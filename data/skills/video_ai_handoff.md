## visual 的写法

按“主体 + 动作 + 场景/背景 + 光线或风格”写一句完整的话，至少 12 个字。例：

- 差：“鲸鱼娘讲解”
- 好：“蓝白配色的鲸鱼娘站在深蓝色数据流背景前，右手一挥，右侧弹出左右对比的两部手机画面”

## 字段词表（用这些词，视频模型更容易理解）

- **shot_size**：特写 / 近景 / 中景 / 全景 / 远景 / 分屏 / 屏幕录制
- **camera**：固定机位 / 缓慢推近 / 拉远 / 横移跟随 / 环绕 / 手持轻晃 / 俯拍
- **transition**（写到下一镜怎么切）：硬切 / 叠化 / 擦除 / 遮罩转场（说明用什么做遮罩）/ 跳切 / 闪白
- **sfx**：具体的声音和触发时刻，例如“字幕弹出时‘叮’一声”
- **bgm**：风格 + 节奏 + 是否有人声，例如“轻快电子风，120BPM，无歌词”。第一镜必须写；后面只在需要变化时写

## 一致性

- 同一角色、同一产品界面在各镜的描述要一致（颜色、位置、样式）。
- 用户的 visual_notes 是全片规范：转场方式、字幕样式、BGM、音效要落到每一镜的对应字段，而不是只写在一处。
- 最后一镜的 transition 可以留空或写“结束画面定格”。
